# Bank Customer Churn Analysis

## Project Overview
An end-to-end data analytics project to understand customer churn in the banking industry.

## Tools & Technologies
- MySQL
- SQL
- Power BI
- DAX
- Data Modeling

## Project Objectives
- Analyze customer churn patterns.
- Identify factors affecting customer retention.
- Understand customer demographics.
- Create interactive Power BI dashboards.

## Dashboards
1. Customer Retention & Churn Analysis
2. Customer Churn Analysis
3. Customer-Level Insights

## Key Skills
SQL Queries, Joins, CTEs, Window Functions, 
Star Schema, DAX, Data Visualization.
